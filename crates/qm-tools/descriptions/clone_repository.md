Clone a repository onto this Mac when the user names one that isn't on disk yet. There's no card: the clone happens now. Nothing is registered; start_crewmate with the folder this returns, and the project appears when the work starts.
- url: the repository's URL, or owner/name for GitHub. GitHub clones go through the user's gh login when it's set up.
- location: the parent folder, absolute or from ~ (optional). Without it, the first search root from settings is used, else the home folder.
The clone goes into a new folder named after the repository. It's refused when that folder already exists: then start work in it instead. To make a brand-new repository, start a crewmate in a new folder and ask it to create one.
