Search tasks kept in memory beyond the context block's list, including closed ones not yet forgotten (clear, compaction, the cap or restart forget them). Numbers can be reused after restart: check the title and project before acting on an old number. Each result is a crewmate (C-n) with its task (T-n); every field is an optional filter. Read only.
- project: a project's name.
- status: statuses to include, e.g. ["running", "held"]; empty means open and active tasks.
- key: a crewmate (C-n), a task (T-n: its crewmates), a branch or a pull request number.
- text: words to find in titles and goals.
- parent: only tasks started from this task.
