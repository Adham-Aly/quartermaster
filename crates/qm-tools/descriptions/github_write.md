Write to GitHub: comment, add or remove labels, or open an issue. Outside your own project it is held for the user's approval. In your own project the app writes it at once.
- action: comment, add_labels, remove_labels or open_issue.
- repo: owner/name (optional; defaults to your project's repository).
- number: the issue or pull request (comment and labels).
- title: the new issue's title (open_issue).
- body: the comment or issue text.
- labels: the labels to add or remove.
