Search tasks still kept in memory, including closed tasks not yet forgotten, beyond what the context block lists. Closed details disappear on clear, compaction, the cap or restart. Numbers can be reused after restart: verify the current title and project before acting on an old number. Every field is an optional filter. Read only.
- project: a project's name.
- status: statuses to include, e.g. ["running", "held"]; empty means open and active tasks.
- key: a task ID, branch name or pull request number.
- text: words to find in titles and goals.
- parent: only tasks started from this task.
