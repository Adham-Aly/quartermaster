# Scratchpad directory

Your scratchpad is `{dir}`. Always use it for temporary files (intermediate results, throwaway scripts, notes, command output, anything that doesn't belong in the project) instead of `/tmp` or any other system temporary folder. It is private to you (your helpers share it), outside the project, and your file tools and `bash` may write there freely. It is removed when your task closes, so put anything worth keeping in the working folder or the evidence folder.
