Defer work without creating a child task, worker or worktree before the trigger. The app keeps the request and starts it when the condition holds; normal start authority, routing and delivery checks still apply. Use start_crewmate for work that should start now; link_tasks only blocks tasks that already exist.
- start: full start_crewmate arguments, including tier/preference. Same authority rules: model/tier/effort/premium need explicit user words; choice_message cites matching, unsuperseded original user-message ID (omit for this turn). Preference is authority-free; citation optional, but any source is checked against its original owner. Named models queue, never substitute.
- trigger: one object tagged by when: "commit", "done", "landed" or "at". For commit/done/landed, include task (e.g. T-0042): wait for a usable commit, finished work, or landed work respectively. For at, include due: a future RFC 3339 timestamp with offset, using the context time/time zone.
Returns schedule (numeric ID), trigger, status, optional task and note. A schedule is not a task; a child appears only when started. Inspect with list_crewmate_starts; cancel a pending one with cancel_crewmate_start, not cancel_schedule. schedule is only a reminder wake, not a deferred start.
