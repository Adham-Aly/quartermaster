Settle finished work under the project's delivery mode and autonomy, once its report says done. Direct pull request: merge it on GitHub at exactly the reported, pushed commit, always as a squash merge whose commit takes the PR's title (checked again as a commit name) and description; refused if the repository or its rulesets don't allow squash merges. Branch only: push the branch; it counts as delivered once GitHub's checks pass on it (you're woken with settled), and the user merges it. No remote: mark the branch delivered and keep it. Plain folder: mark it delivered; its edits are already in the folder, so nothing is merged, pushed or held. Build in place: merge the branch into the user's checkout, only if its working tree is clean. Work that delivered an answer, not code, is closed with its answer kept. A plan closes only once approved (normal autonomy) or finished (auto). Under normal autonomy the app holds it for the user's approval and shows a card; the user's answer comes back to you. Refused when the review hasn't passed at the reviewed level, checks aren't green, a blocking task hasn't landed, or the head isn't the one reported done.
