Clone a repository the user names that isn't on this Mac yet. No card: it happens now. Then start_crewmate with the folder this returns; the project appears when work starts.
- url: the repository's URL, or owner/name for GitHub (through the user's gh login when set up).
- location: the parent folder, absolute or from ~ (optional; default: the first search root in settings, else home).
It's refused when the repository's folder already exists: start work there instead. For a brand-new repository, start a crewmate in a new folder and ask it to make one.
