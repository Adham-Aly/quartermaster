Propose linking, cloning or creating a project. Always held for the user to confirm or change the location; nothing is linked, cloned or created until they do.
- action: link (a folder that exists), clone (a repository the user named) or create (only when the user asks for a new project).
- name: the project's name.
- path: the folder to link (link only).
- url: the repository to clone (clone only).
- location: the parent folder for a clone or a new project (optional; the app suggests one).
