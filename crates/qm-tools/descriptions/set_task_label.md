Move one of your crewmates to another task, or to a new one of its own. A task (T-n) groups crewmates on one thing; a crewmate's name (C-n) never changes. Its artifacts and scratchpad follow, and it is told; worktree, branch, project and supervisor stay. An emptied task goes by itself.
- crewmate: e.g. C-0042.
- task: open task to join, e.g. T-0017; omit for a new one.
